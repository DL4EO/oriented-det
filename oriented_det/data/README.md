# Data loaders and evaluation

User guide: [Data Loading](../../docs/user-guide/data.md). Config: [Configuration](../../docs/user-guide/configuration.md) (`dataset` section).

- **Spatial preprocessing** — `preprocessing.py`: `resize_mode` **`fixed`** (stretch to canvas), **`pad`** (uniform scale so the longer edge equals `max(H, W)` then zero-pad to `target_size`; aspect ratio preserved), **`crop`** (native-resolution crop/pad to `target_size`; random crop in training, center crop in val/inference). Used from `oriented_det.runtime.collate` and `oriented_det.runtime.inference`.
- **Training flips** — `flips.py`: `apply_random_train_flips` (MMRotate `RRandomFlip` parity: horizontal / vertical / diagonal at 25% each when all three enabled). Used from `oriented_det.runtime.collate`. `transforms.py` also exposes `HorizontalFlip`, `VerticalFlip`, `DiagonalFlip` for notebooks.
- **mAP** — `evaluation.py`: ``compute_oriented_map`` uses **exact CPU polygon IoU** when ``use_exact_rotated_iou=True`` (Shapely when installed). Set ``evaluation.use_exact_rotated_iou: false`` in training config (or pass ``use_exact_rotated_iou=False``) for GPU sampling IoU during validation — faster, approximate. GT-cover / accuracy on mAP epochs follow the same flag. Final detection NMS is unaffected.
- **DOTA** — `dota.py`: `DOTADataset`, `DOTAAnnotation`, loaders. Multi-root tiles: `train_tiles_dirs` / `val_tiles_dirs` in config → `resolve_dota_tile_roots`, `build_dota_split_dataset` (`ConcatDataset`), `collect_dota_image_paths`, **`collect_dota_split_image_paths`**, `dota_label_path_for_image`. Optional **`filter_empty_gt`** (config `dataset.filter_empty_gt`, default `false`) drops tiles with no objects after `difficult_strategy` / class filters — used in **training** and MMRotate parity (`dota_le90_3x.json`). **`make preds` / `make metrics`** enumerate **all** tiles (`filter_empty_gt=False` in `save_predictions.py`).
- **Airbus Playground CSV** — `airbus_playground.py`: `discover_airbus_tiles`, `generate_airbus_playground_csvs` (writes integer **fold** ids; default val fold is **0**), `dated_playground_csv_filenames` / `resolve_playground_csv_filenames` (paired `annotations_YYYYMMDD.csv` + `split_YYYYMMDD.csv` from `tools/generate_airbus_playground_csv.py`), `detect_airbus_split_csv_format`, `AirbusPlaygroundCSVDataset` (pass `annotations_file`, `split_file`, and `val_split_id` to match training config; legacy `train`/`val` strings in split CSVs are still accepted). Optional **`filter_empty_gt`** (config `dataset.filter_empty_gt`) drops tiles with no objects after `map_labels` / `ignore_labels` / `difficult_strategy` — applied to the **train** split only in `tools/train.py` (val keeps all tiles).
- **`dota_classes.py`** — Canonical DOTA v1.0 class list (`DOTA_V1_CLASSES`, `DOTA_V1_CLASS_SET`) shared with training tools and deploy metadata generation.
