# Dataset base configs

JSON fragments included via `"_base_"` in training recipes under the framework repo root.

- **`dota_le90.json`** — Tiled DOTA v1.0 train/val folders and dataset-specific normalization (from `odet stats`). All DOTA 1× recipes inherit this (Oriented R-CNN, Faster R-CNN, FCOS, RetinaNet) so satellite tiles are centered with DOTA mean/std rather than ImageNet defaults. Zoo recipes then union **train+val** via `train_tiles_dirs`. `test_tiles_dir` is the same val folder, so `test_map` / `make eval-test` is the **leaky** val sweep at the test score floor. `make dota-submit` ignores that path and requires the unlabeled official test.
- **`hrsc2016.json`** — Official HRSC2016 layout (`dataset.format: hrsc2016`), ImageSets **trainval / test**, square pad-800 default. `val_split` and `test_split` are both **`test`**, so periodic val and `test_map` score the same held-out ImageSets test at two score floors. Oriented R-CNN, Faster R-CNN, and FCOS 1×/3× override to `keep_ratio` + pad-32. Eval uses the same whole-image path as training; DOTA recipes stay on `fixed` sliding windows. Those test images are **not** in training.
- **`fair1m.json`** — Tiled FAIR1M after `odet fair1m-to-dota` + `odet tile-dota` (1024 / overlap 200). Raw dump is `/path/to/data/FAIR1M` (official train 16,488 + val 8,287). Convert with `--splits train,val` (no `--val-fraction` unless the dump has no val; default `--image-format original` copies JPEG/PNG). Point `train_tiles_dir` / `val_tiles_dir` at `FAIR1M-dota/{train,val}/tiles_1024` — not the parent split folder (that still holds full images). `test_tiles_dir` is the same val folder, so `test_map` is that leaky sweep. Recipes use `dataset.format: dota` and finetune the matching DOTA 1× Hub checkpoint (no FAIR1M zoo). Train is official **train** tiles only; val is **not** in training. Faster R-CNN 1× local tiled-val mAP50 **36.70%** (mid-30s is expected; see [Data guide — FAIR1M](../../../docs/user-guide/data.md#local-1x-faster-rcnn)).
- **`ssdd.json`** — Native SSDD (`dataset.format: ssdd`). Default `data_root` `/path/to/data/Official-SSDD-OPEN` (walks into `RBox_SSDD/voc_style`). Official last-digit **train / test**, keep-ratio 608 + pad-32. No tiling. `val_split` and `test_split` are both **`test`**, so `make eval-val` and `make eval-test` score the same held-out set. Faster R-CNN **12-epoch** 1× finetunes DOTA Hub (no SSDD zoo). Expected AP50: [data.md](../../../docs/user-guide/data.md#ssdd-1x-faster-rcnn).
- **`hrsid.json`** — Native HRSID (`dataset.format: hrsid`). Default `data_root` `/path/to/data/HRSID_JPG` (`JPEGImages/` + `annotations/*2017.json`). Official **train / test** (no val), keep-ratio 800 + pad-32. No tiling. `val_split` and `test_split` are both **`test`**, so `make eval-val` and `make eval-test` score the same held-out set. **12-epoch** 1× recipes finetune DOTA Hub (no HRSID zoo). Protocol: [data.md](../../../docs/user-guide/data.md#hrsid-1x).
- **`ossdd.json`** — OSSDD Sentinel-1 VH exported to DOTA folders (`dataset.format: dota`). `train` / `val` / `test` under `/path/to/data/OSSDD-dota`. Normalization matches the DOTA checkpoint these recipes finetune (`dota_le90.json` mean/std). The export already applied clip / log10 / per-chip min-max. `test_tiles_dirs` is the held-out test split for `make eval-test` and `evaluation.test_map`. Train still drops empty tiles (`filter_empty_gt`); test scoring keeps them.

Default Oriented R-CNN DOTA recipes: [`dota_le90_1x.json`](../../oriented_rcnn/dota_le90_1x.json) (full 1× baseline and default `make train`), [`dota_le90_3x.json`](../../oriented_rcnn/dota_le90_3x.json) (inherits 1×). HRSC2016: [`hrsc2016_le90_1x.json`](../../oriented_rcnn/hrsc2016_le90_1x.json), [`hrsc2016_le90_3x.json`](../../oriented_rcnn/hrsc2016_le90_3x.json). FAIR1M: [`fair1m_le90_1x.json`](../../oriented_rcnn/fair1m_le90_1x.json). HRSID: [`hrsid_le90_1x.json`](../../oriented_rcnn/hrsid_le90_1x.json). SSDD Faster R-CNN: [`ssdd_le90_1x.json`](../../rotated_faster_rcnn/ssdd_le90_1x.json).

For **Airbus Playground CSV** datasets, keep dataset JSON in your own config tree and inherit `@odet:configs/_base_/...` fragments. See [Data loading](../../../docs/user-guide/data.md#airbus-playground).
